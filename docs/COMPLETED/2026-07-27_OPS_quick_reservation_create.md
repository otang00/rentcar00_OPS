# 2026-07-27 — 퀵 예약생성 모달 추가

## 완료 내용

- 차량 상세의 예약 생성 모달 상단 버튼을 `AI / IMS / 퀵` 3개로 정리했다.
- `퀵` 버튼을 누르면 최소 입력 모달이 열린다.
- 입력 맨 위는 차량선택이다.
- 입력 필드는 차량, 이름, 전화번호, 가격, 배차일시, 반납일시, 배차위치, IMS포함 체크다.
- 가격은 선택 입력이며 비우면 IMS 통과용 기본값으로 들어간다.
- 배차위치를 비우면 `사무실`로 저장한다.
- 반납위치는 `사무실`, 생년월일은 `1900-01-01`, 유입경로는 `퀵`, 메모는 `퀵 예약생성` 기본값을 사용한다.
- IMS포함 체크가 켜져 있으면 기존 IMS 예약생성 payload 검증을 통과한 뒤 예약 생성 흐름으로 이어진다.

## 핵심 기준

- 현장 입력 시간을 줄이는 보조 생성 기능이다.
- 기존 AI 파서/IMS 가져오기 흐름은 유지한다.
- IMS가 요구하는 필수값은 사용자가 안 쓰는 값도 기본값으로 채운다.

## 주요 파일

- `lib/features/status_board/detail/presentation/status_board_detail_page.dart`

## 남은 확인

- 실기기에서 날짜/시간 picker와 숫자 입력 formatter가 현장 입력 방식에 맞는지 확인이 필요하다.
- 퀵 기본값은 편의 기준이므로 운영 중 더 적합한 기본값이 있으면 별도 phase로 조정한다.
